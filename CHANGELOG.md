# Changelog

## v0.1.0 — 2026-11-07

- Maintainer confirmed the patch works in-game with MHGU 1.4.0. Exact emulator version and detailed test coverage were not recorded.
- Promoted the existing ExeFS patch to the first stable release; patch addresses and instruction bytes are unchanged from v0.1.0-alpha.
- Added a release packaging script, installation ZIP, and SHA-256 checksum.
- Updated English and Chinese installation and verification documentation.

维护者已确认游戏内实测可用。本次发布沿用 alpha 版补丁指令，新增发行包、校验文件与打包脚本，并更新中英文说明；不代表其他游戏版本或模拟器均已验证。

- Initial experimental conversion of community Mark Boss and Auto Display Map codes to an IPSwitch ExeFS patch.
